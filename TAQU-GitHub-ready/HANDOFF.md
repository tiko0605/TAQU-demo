# TAQU 开发交接

## 交接基准

本交接基于 2026-10-13 对当前工作目录的只读审查。当前项目目录不是 Git 仓库，没有 Git remote，也没有发现 `package.json`、锁文件、测试配置、构建配置或部署配置。当前环境没有 GitHub CLI，不能据此确认 GitHub 登录状态。

当前应继续使用的文件：

- `outputs/index.html`
- `outputs/app.js`
- `outputs/styles.css`

`outputs/TAQU-demo.zip` 内只有这三个文件，且其 SHA-256 与 `outputs/` 根目录同名文件逐一匹配。`outputs/TAQU-demo/` 是旧副本：其 JS 和 CSS 与当前源文件哈希不同，不能用于后续开发或发布。此审查没有改写或删除这些文件。

## 架构与业务边界

- 单页静态应用。`index.html` 加载样式、Lucide CDN 和 `app.js`。
- `app.js` 同时包含模拟数据、页面渲染函数、导航/事件绑定和状态持久化，没有拆分组件。
- `styles.css` 是唯一应用样式文件。
- 无服务器端代码、身份验证、数据库、API 请求、支付或真实救助机构集成。
- 业务操作和指标均为本地演示逻辑，不会产生真实申请、救助、报名、支付或广告投放。

主要页面：地图首页、附近地点、地点详情、社区（搭子/分享/活动）、救助首页、领养与申请、喂养点、动物上报与进度、公益记录、收藏、个人资料、积分、商户合作与推广效果、地点信息反馈和反馈详情。

## 已知限制和需要继续处理的事项

1. **数据只在当前浏览器本地保存。** `localStorage` 的 `taqu-state` 和 `taqu-favorites` 不跨设备/浏览器同步，没有登录、备份或迁移 UI。不同部署域名也会形成不同存储来源。
2. **没有自动化回归测试。** `node --check outputs/app.js` 通过只代表脚本语法有效；仍需真实浏览器手动检查完整交互和窄屏布局。
3. **外部资源未本地化且版本未锁定。** 图标来自 `lucide@latest`、字体来自 Google Fonts、图片来自 Unsplash；网络受限时可能缺失。
4. **地点、政策、活动、人物、公益结果和商业指标是模拟内容。** 发布时应显著保持 Demo 属性，不作为现实承诺或事实数据。
5. **没有构建、测试或部署流水线。** 项目在有浏览器和静态 HTTP 服务的情况下直接运行。
6. **旧副本易造成混淆。** 保留在 `outputs/TAQU-demo/`，目前审查只标注了差异，未删除或同步它。
7. **权属与公开许可未验证。** 文件不能证明用户是否拥有将代码、文字或视觉素材迁移到个人仓库的权利；若涉及公司/第三方资料，迁移前须先确认授权。
8. **浏览器里可能有用户填写的联系信息。** 这些内容不在静态源文件或 ZIP 中，但若手动导出 localStorage，会包含个人数据，不能直接提交到 Git。

## 外部运行依赖

- 现代浏览器。
- 建议使用 Python 自带静态服务：在 `outputs/` 运行 `py -m http.server 8000`，访问 `http://localhost:8000/`。
- `py`/Python 命令是否在个人电脑安装，需要迁移后验证。
- 运行时外部请求：`unpkg.com`、`fonts.googleapis.com`、`fonts.gstatic.com`、`images.unsplash.com`。
- 无环境变量；没有发现数据库、后端 API、地图平台、云存储、认证或支付服务配置。
